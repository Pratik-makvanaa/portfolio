# Portfolio

A modern portfolio website built with **Next.js, React, TypeScript, and Tailwind CSS**.

## 🧰 Technologies

### Frontend
- Next.js
- React.js
- TypeScript
- Tailwind CSS

### UI & Animation
- Framer Motion
- GSAP
- Lenis
- Radix UI
- Lucide React

### Development Tools
- Node.js
- npm
- Git
- GitHub

## ⚙️ Installation

### Prerequisites

Make sure you have installed:

- Node.js 18+
- npm
- Git

### Clone the Repository

```bash
git clone https://github.com/Pratik-makvanaa/portfolio.git
cd portfolio
```

### Install Dependencies

```bash
npm install
```

## 🚀 Run Development Server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
