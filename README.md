## ⚙️ Local Setup

### Prerequisites

- Node.js 18+
- npm

### Installation

```bash
git clone https://github.com/Pratik-makvanaa/portfolio.git
cd portfolio
npm install
```

### Run in Development

```bash
npm run dev
```

Open **http://localhost:3000** in your browser.

### Production Build

```bash
npm run build
npm run start
```
